# KeyMe Pass — Feedback

Public issue tracker for [KeyMe Pass](https://www.keymepass.com),
a local-first password manager.

**This repository does not contain source code.** It exists so you can
report bugs and request features in the open.

## Report a bug

[Open an issue](https://github.com/keymepass/feedback/issues/new/choose).
Helpful things to include:

- Platform and version (iOS / Android / HarmonyOS / browser extension)
- OS version and device model
- What you expected, and what happened instead
- Steps to reproduce, if you know them

## Security issues

**Please don't open a public issue for security problems.**
Email security@keymepass.com instead — we'll respond and credit you
if you'd like.

## Not a support channel

For account or billing questions, contact support@keymepass.com —
those often involve personal details that shouldn't be public.
